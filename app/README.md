# Kaira君を探せ（モックアプリ）

「ウォーリーを探せ」形式で Kaira君を探すアプリ。画面は2つ。

- **作る**（`/create`）：背景を選び、パレットで選んだ Kaira君をクリックで置いて問題を作り、登録する。
  背景と偽物の Kaira君は Gemini で新しく作ることもできる（本物は用意した2枚だけで、作れない）。キャラは物の陰には隠さない。登録すると YOLO に解かせ、AI を出し抜けたかを表示する
- **解く**（`/`）：用意した問題（25問）と、ほかの人が作った問題（一覧に ★）を解く。YOLO の検出結果をヒントに使う

用意した問題は、`gen_img.question.config.QUESTIONS` の配置で本物と偽物を背景に貼っただけの画像（物陰に隠さず、AI でなじませもしない）。
`build.py` が、画像・正解の枠・YOLO の検出結果を `app/data/builtin/` に作る。アプリは起動時にこれを読むだけ。

## 起動

```sh
uv run python app/build.py   # 用意した問題の画像・正解の枠・YOLO の検出結果を作る（初回と、問題の配置を変えたときだけ。約3分）
# YOLO のモデルや推論の設定だけを変えたときは uv run python app/build.py --detections-only（約20秒）
uv run python app/server.py   # 解く http://localhost:8770/ 、作る http://localhost:8770/create
```

- YOLO は `app/data/model/best.pt`（本物の Kaira君だけを見つけるよう学習したもの。クラスは `kaira` の1つ）を使う。
  GPU は要らない（CPU で画像1枚 約0.6秒）。torch・ultralytics はプロジェクトの依存に入っている（`uv sync` で入る）。
  Linux で普通に入れると GPU 用の CUDA（約1.5GB）まで入るので、`pyproject.toml` で CPU 版の torch を使う設定にしてある
- 背景と偽物の生成には、リポジトリ直下の `.env` に書いた `GEMINI_API_KEY` を使う（起動時に自動で読む）。なくても既存の背景とキャラで問題は作れる
- 作った問題・生成した背景・プロンプトで作った偽物は `app/data/user/` に保存される（git には入れない）。用意した背景とキャラの絵は `app/data/background/`・`app/data/kaira/`
- YOLO の検出結果は保存して使い回す：用意した問題は `build.py` が `app/data/builtin/detections.json` に、作った問題は登録のときに `app/data/user/questions/detections.json` に保存する。
  どのモデル・設定で作った結果かも一緒に保存してあり、`app/data/model/best.pt` を置き換えたり `config.py` の推論の設定を変えたりすると、起動時に自動で検出し直して保存し直す
- キャラを背景の線の太さに合わせて描くので、ある背景・大きさで初めて置くキャラは表示まで1〜3秒かかる（2回目からはすぐ）

`app/data/model/best.pt` がないときは、本物の枠を少しずらして YOLO の出力に見立てたモックでヒントを出す（画面右上に「ヒント: モック」と出る）。

`app/data/model/best.pt` の成績（用意した25問、確信度 0.1 以上の候補、推論の画像サイズ 1280）：本物を候補に挙げたのは24問（見つけられないのは茂みの上の問題18だけ）。
候補はどの問題も0〜1個（本物だけ）で、偽物はどれも確信度 0.05 以下（本物と見分けられている）。
画像サイズ 1024 で推論すると、幅120px ほどの小さめの本物（問題13・15）の確信度が 0.03 以下に下がって22問になるので、1280 で推論している（`config.py` の `YOLO_IMAGE_SIZE`）。Gemini で作った京都駅の背景に置いた本物は見つけられなかった（知らない背景には弱い）。

## 作り方（作る画面）

1. 背景を選ぶと、すぐ右に表示される。新しく作るときは「Gemini で新しい背景を作る」を開き、2段階で作る
   - ① 短いテーマ（例：京都駅）を書いて「説明を作る」：文章のモデル（`gemini-2.5-flash`）が、絵にする場面の説明を日本語で詳しく書く（実在の場所なら、その場所とわかる建物や名物を入れる）
   - ② 説明を読んで、必要なら書き直して「この説明で背景を作る」：説明と、共通の指示（`config.py` の `BACKGROUND_BASE_PROMPT`。白黒の線画・上から見下ろす広い床・生き物は少なめ）で画像のモデルが描く（約20秒）
   - 「Kaira君っぽい生き物を紛れ込ませる」を選ぶと、ふだんは描かせない Kaira君に似た生き物（`DECOY_KAIRA_PROMPT`）をわざと描かせる。人は迷いやすくなるが、YOLO は引っかからなかった
2. パレットで本物（2種類の向き）か偽物を選び、背景をクリックすると、そこに置かれる（お絵かきソフトで色を選んで塗る感じ）
   - カーソルに置くキャラが半透明で出る。**緑の枠なら置ける、赤の枠ならほかのキャラと重なる（または画像からはみ出す）ので置けない**
   - 置いたキャラの周りは赤く塗られ、置けない場所が見える
   - 本物は1体だけ。もう一度置くと前の本物は消える。右クリックか消しゴムで消せる
   - 大きさ（60〜180px）と左右反転を選べる。名札（本物・偽物の特徴）を表示して確かめられる
3. パレットにない偽物は「新しい偽物を作る」で作れる（例：頭に小さなシルクハットをのせる）。本物の絵を Gemini に渡し、書いたとおりに描き変えさせて、
   白黒＋透明の絵に変換して見せる。気に入ったら「見分けるポイント」（名前）を書いて保存するとパレットに入る（＊付き）。**名前を書かないと保存されない**。
   本物は作れない（答えが用意した本物の絵だけになるように）
4. 本物1体と偽物1体以上を置いたら、問題の名前（必須。書かないと登録できない）と作った人の名前を入れて登録する。
   YOLO に解かせて、候補（確信度 0.1 以上）の上位5つに本物が入らなければ「AI を出し抜きました！」と出る。
   YOLO が一番本物らしいと判断したのが偽物なら、その偽物も表示する

偽物を増やす・小さくする・本物との違いが小さい偽物を作る・背景が細かいほど難しい。

### Gemini で作るときの注意（2026-11 に試した結果。評価は `exp/code/prompt_eval/`）

- 偽物：元の絵（ポーズ・線・しっぽ）をほぼそのまま保ち、頼んだ物だけ描き足す。シルクハット・メガネ・口ひげ・羽・しま模様を試し、どれも使える出来だった。
  描き足す物を黒く塗りつぶすことがあったので、指示文（`config.py` の `KAIRA_PROMPT`）に「塗りつぶさず線だけで描く」を入れてある
- Gemini の安全チェックで断られることがある（「しま模様」で1回あった）。そのときは画面に「別の言い方で書いてみてください」と出る。画像のない応答は2回まで自動で頼み直す
- 背景：テーマだけを渡すと、実在の場所（京都大学など）を指定してもその場所らしくならないことがあったので、場面の説明を先に書かせる2段階にした。
  「京都駅」では京都タワー・大階段・ガラスの大屋根・新幹線が描かれた。おもちゃ屋さんのように箱や看板が多い場面は、文字を禁止しても「GAMES」などの文字が入りやすい

## 遊び方（解く画面）

- 画像をクリックして答える。ホイールで拡大、ドラッグで移動
- 偽物を押すと「偽物！（王冠）」のように見分けポイントが出て、おてつきが増える
- 「ヒント（YOLO）」：YOLO の候補（確信度 0.1 以上、高い順）の場所を丸で示す。YOLO の候補はたいてい本物1つだけなので、
  難易度ごとの丸の数まで、偽物の場所をランダムに選んで足す（丸の数で答えがわからないように）。丸の中心はキャラから少しずらしてある。押すたびに丸が小さくなる。
  偽物の丸には確信度がないので、確信度はヒントでは出さない。YOLO が本物を候補に挙げていなければ丸の中に本物はいない。そういう問題は一覧に「AIも苦戦」と出る
- 「答えを見る」：本物（緑）・偽物（橙と見分けポイント）・YOLO の候補（青い点線と確信度）を表示する

## 難易度（`config.py` の `LEVELS`）

| 難易度 | 丸の数（最大。YOLO の候補＋足りない分は偽物） | 丸の大きさ |
|---|---|---|
| かんたん | 2 | キャラの枠の大きさ × 1.0 |
| ふつう | 5 | × 1.2 |
| むずかしい | 10 | × 1.5 |
| 鬼 | ヒントなし | |

## ファイル

| ファイル | 中身 |
|---|---|
| `server.py` | サーバー（標準ライブラリだけで動く） |
| `create.py` | 問題を作る：背景（2段階）と偽物の生成（Gemini）、キャラの絵（線の太さ・濃さを背景に合わせる）、合成、保存 |
| `detect.py` | YOLO での検出と、モックの検出 |
| `config.py` | モデルの場所・難易度・偽物の見分けポイント・作るときの設定（大きさの範囲・すき間・背景と偽物を作るプロンプト） |
| `build.py` | 用意した問題の配置から、貼っただけの問題画像・本物と偽物の枠・YOLO の検出結果を作る |
| `static/solve.html` | 解く画面 |
| `static/create.html` | 作る画面 |
