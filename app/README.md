# Kaira君を探せ（モックアプリ）

「ウォーリーを探せ」形式で Kaira君を探すアプリ。画面は2つ。

- **作る**（`/create`）：背景を選び、パレットで選んだ Kaira君をクリックで置いて問題を作り、登録する。
  背景と Kaira君（本物・偽物）は Gemini で新しく作ることもできる。キャラは物の陰には隠さない。登録すると YOLO に解かせ、AI を出し抜けたかを表示する
- **解く**（`/`）：用意した問題（`img/harmonized_question/question/`）と、ほかの人が作った問題（一覧に ★）を解く。YOLO の検出結果をヒントに使う

## 起動

```sh
uv run python app/build_answers.py   # 用意した問題の正解の枠を answers.json に書き出す（問題の配置を変えたときだけ）
uv run --env-file .env \
  --index https://download.pytorch.org/whl/cpu --index-strategy unsafe-best-match \
  --with torch==2.6.0 --with torchvision==0.21.0 --with ultralytics \
  python app/server.py               # 解く http://localhost:8770/ 、作る http://localhost:8770/create
```

- YOLO は `data/best.pt`（本物の Kaira君だけを見つけるよう学習したもの。クラスは `kaira` の1つ）を使う。
  GPU は要らない（CPU で 1024px の画像1枚 約0.5秒）。Linux で普通に ultralytics を入れると GPU 用の torch と CUDA（約1.5GB）まで落としてくるので、CPU 版の torch を指定している
- 背景と Kaira君の生成には `.env` の `GEMINI_API_KEY` を使う（`--env-file .env`）。なくても既存の背景とキャラで問題は作れる
- 作った問題・生成した背景・プロンプトで作った Kaira君は `app/data/` に保存される（git には入れない）
- キャラを背景の線の太さに合わせて描くので、ある背景・大きさで初めて置くキャラは表示まで1〜3秒かかる（2回目からはすぐ）

`uv run python app/server.py` だけでも起動できる。そのときは ultralytics が入っていないので、

本物の枠を少しずらして YOLO の出力に見立てたモックでヒントを出す（画面右上に「ヒント: モック」と出る。`data/best.pt` がないときも同じ）。

`data/best.pt` の成績（問題24問）：YOLO の推定（確信度の高い順）で本物が 1位 15問、上位2 16問、上位5 18問。
偽物はどれも確信度 0.05 以下で、本物と見分けられている。見落とすのは、ほとんどが物陰に隠れた本物。

## 作り方（作る画面）

1. 背景を選ぶと、すぐ右に表示される。新しく作るときは「Gemini で新しい背景を作る」を開き、どんな場面を描くかを日本語で書く（約20秒）
2. パレットで本物（2種類の向き）か偽物を選び、背景をクリックすると、そこに置かれる（お絵かきソフトで色を選んで塗る感じ）
   - カーソルに置くキャラが半透明で出る。**緑の枠なら置ける、赤の枠ならほかのキャラと重なる（または画像からはみ出す）ので置けない**
   - 置いたキャラの周りは赤く塗られ、置けない場所が見える
   - 本物は1体だけ。もう一度置くと前の本物は消える。右クリックか消しゴムで消せる
   - 大きさ（60〜180px）と左右反転を選べる。名札（本物・偽物の特徴）を表示して確かめられる
3. パレットにない Kaira君は「プロンプトで Kaira君を作る」で作れる（例：頭に小さなシルクハットをのせる）。本物の絵を Gemini に渡し、書いたとおりに描き変えさせて、
   白黒＋透明の絵に変換してパレットに足す（＊付きで出る）。偽物には「見分けるポイント」を付ける。描き変えた本物は YOLO が見つけにくいことがある
4. 本物1体と偽物1体以上を置いたら、問題の名前と作った人の名前を入れて登録する。YOLO に解かせて、上位5候補に本物が入らなければ「AI を出し抜きました！」と出る。
   YOLO が一番本物らしいと判断したのが偽物なら、その偽物も表示する

偽物を増やす・小さくする・本物との違いが小さい偽物を作る・背景が細かいほど難しい。

### Gemini で作るときの注意（2026-11 に試した結果。評価は `exp/code/prompt_eval/`）

- Kaira君：元の絵（ポーズ・線・しっぽ）をほぼそのまま保ち、頼んだ物だけ描き足す。シルクハット・メガネ・口ひげ・羽・しま模様・笑顔を試し、どれも使える出来だった。
  描き足す物を黒く塗りつぶすことがあったので、指示文（`config.py` の `KAIRA_PROMPT`）に「塗りつぶさず線だけで描く」を入れてある
- Gemini の安全チェックで断られることがある（「しま模様」で1回あった）。そのときは画面に「別の言い方で書いてみてください」と出る。画像のない応答は2回まで自動で頼み直す
- 背景：日本語のテーマでも、白黒の線画で画面いっぱいに描き込まれた絵になる。おもちゃ屋さんのように箱や看板が多い場面は、文字を禁止しても「GAMES」などの文字が入りやすい

## 遊び方（解く画面）

- 画像をクリックして答える。ホイールで拡大、ドラッグで移動
- 偽物を押すと「偽物！（王冠）」のように見分けポイントが出て、おてつきが増える
- 「ヒント（YOLO）」：YOLO が「本物らしい」と推定した場所を、確信度の高い順に上位いくつか（難易度で変わる）丸で示す。押すたびに丸が小さくなる。
  上位に本物が入っていなければ丸の中に本物はいない。そういう問題は一覧に「AIも苦戦」と出る
- 「答えを見る」：本物（緑）・偽物（橙と見分けポイント）・YOLO の推定の上位10（青い点線と確信度）を表示する

## 難易度（`config.py` の `LEVELS`）

| 難易度 | ヒントの丸 | 丸の大きさ | 上位に本物が入る問題（best.pt） |
|---|---|---|---|
| かんたん | YOLO の推定の上位 2 | 検出した枠の大きさ × 1.0 | 16 / 24 |
| ふつう | 上位 5 | × 1.2 | 18 / 24 |
| むずかしい | 上位 10 | × 1.5 | 18 / 24 |
| 鬼 | ヒントなし | | |

## ファイル

| ファイル | 中身 |
|---|---|
| `server.py` | サーバー（標準ライブラリだけで動く） |
| `create.py` | 問題を作る：背景と Kaira君の生成（Gemini）、キャラの絵（線の太さ・濃さを背景に合わせる）、合成、保存 |
| `detect.py` | YOLO での検出と、モックの検出 |
| `config.py` | モデルの場所・難易度・偽物の見分けポイント・作るときの設定（大きさの範囲・すき間・Kaira君を描き変えるプロンプト） |
| `build_answers.py` | 用意した問題の配置から、本物・偽物の見えている範囲の枠を作る |
| `static/solve.html` | 解く画面 |
| `static/create.html` | 作る画面 |
| `train_yolo.ipynb` | YOLO を学習するノートブック（Google Colab 用） |

## YOLO の学習（`train_yolo.ipynb`）

Google Colab で開き、GPU ランタイムで上から実行する。

- データはドライブの `ai_worry/dataset/`（`images/{train,val}`、`labels/{train,val}`。YOLO 形式）
- クラス名は、ラベルのクラス数が 1 なら `kaira`、2 なら `real`, `fake` にする（ノートブックの `CLASS_NAMES` で変えられる）
- 学習したモデルはドライブの `ai_worry/models/yolo26n_kaira.pt` に保存される。リポジトリの `data/best.pt` に置き換えるとアプリで使える

問題20は配置を変えた後に画像を作り直していないので、正解の枠が画像と合わない。そのため今は出していない（`config.py` の `SKIP_QUESTIONS`）。
